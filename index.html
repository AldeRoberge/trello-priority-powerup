Guide d’installation

Trello Cerveau n’est pas (encore) dans le répertoire officiel des Power-Ups : vous l’ajoutez à votre compte en quelques minutes en créant un Power-Up « personnalisé » qui pointe vers un site GitHub Pages. Personnalisez les noms ci-dessous : les étapes, les liens et le script s’adaptent.

Votre installation

Dépôt :
Site :

  1. Créer votre copie du code automatisable

    Ce script crée le dépôt sur votre compte GitHub, y met le nom , active GitHub Pages, attend la mise en ligne, puis vous guide dans Trello (créer le Power-Up lui-même ne peut pas être scripté). Il nécessite GitHub CLI et Git.

    Vous préférez tout faire à la main ? Sautez cette étape : forkez le dépôt d’origine, activez Pages (source : GitHub Actions), puis suivez les étapes suivantes.

  2. Créer le Power-Up dans Trello

    1. Ouvrez trello.com/power-ups/admin (connecté à votre compte Trello).
    2. Cliquez sur Create new Power-Up.
    3. Nom : Trello Cerveau. Choisissez votre espace de travail (workspace), renseignez un courriel de contact et un nom d’auteur.
    4. Dans Iframe connector URL, collez l’adresse ci-dessous :
    https://alderoberge.github.io/trello-priority-powerup/index.html

    Créez ensuite le Power-Up.

  3. Activer les six capacités

    Dans l’onglet Capabilities, cochez uniquement :

    • card-badges
    • card-detail-badges
    • card-back-section
    • board-buttons
    • list-sorters
    • on-enable

    Ne cochez pas card-buttons, list-actions ni on-disable. Enregistrez.

  4. Ajouter le Power-Up à un tableau

    1. Ouvrez le tableau Trello où vous voulez l’utiliser.
    2. Menu du tableau → Power-Ups → Ajouter des Power-Ups → onglet Custom.
    3. Trouvez Trello Cerveau et cliquez sur Ajouter. Une fenêtre de bienvenue s’affiche.

    Si des fonctions manquent (badge, entrée « Priorité » dans Trier par…), retirez le Power-Up du tableau, rechargez la page Trello puis ajoutez-le de nouveau.

  5. Définir une première priorité

    Ouvrez une carte : la fenêtre Cerveau s’ouvre. Réglez l’urgence, l’impact et la facilité avec les curseurs (ou touchez un palier sur la barre de chaleur). Le score et le palier (ex. 7.9 · Urgent) apparaissent en badge sur la carte.

    Pour trier une colonne : menu … de la liste → Trier par… → Priorité.

  6. Personnaliser optionnel

    Le bouton Paramètres du Cerveau (menu du tableau) donne accès à :

    • Mon profil : langue, ton de l’assistant, sections visibles dans l’éditeur.
    • Assistant IA : compatible OpenAI et OpenRouter — vous fournissez votre propre clé, stockée en privé sur votre compte Trello.
    • Statuts : associer vos listes à des catégories (à faire, en cours, terminé…).
    • Gantt (bêta) : vue chronologique du tableau à partir des dates de début et d’échéance.

  7. Fonctions avancées optionnel

    • Tri automatique : réordonne la carte dès que sa priorité change. Nécessite votre propre copie du dépôt avec votre appKey dans rest-config.js, l’onglet API Key du Power-Up (avec votre domaine dans Allowed origins), puis Autoriser Trello dans les paramètres.
    • Synchronisation Outlook : Entra, Power Automate ou export .ics.
    • Google Sheets : guide de synchronisation.
Dépannage
  • Le Power-Up n’apparaît pas dans Custom : vérifiez qu’il est créé dans le même espace de travail que le tableau.
  • Trello affiche une erreur au chargement : l’URL du connecteur doit se terminer par /index.html et s’ouvrir dans le navigateur.
  • Badge ou bouton absent : vérifiez les six capacités, puis retirez et réajoutez le Power-Up.
  • « Priorité » absent de Trier par… : ouvrez le menu … de la liste (pas du tableau) et confirmez que list-sorters est coché.
